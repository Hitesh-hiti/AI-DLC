# Architecture & Engineering Guardrails

- Respect existing repository architecture and framework structure.
- Prefer reuse over new dependencies.
- Enforce security and authorization at the correct boundary.
- Never commit secrets.
- Maintain API/data contract compatibility unless a breaking change is approved.
- Keep modules cohesive and interfaces explicit.
- Follow approved observability, error handling, accessibility, and performance patterns.
- All implementation and automation must map to a story and acceptance criteria.
