# Product Overview — AI DLC Enterprise Workflow

This project implements an AI-assisted SDLC and QA workflow using Kiro, Jira, Zephyr, Git,
Playwright/Selenium, and CI/CD. The system emphasizes human approval, end-to-end traceability,
continuous feedback, and safe adaptation to enhancements.

Primary roles: Owner, Product Owner, Architect, UI/UX Designer, Developer, Tester.

Core lifecycle:
Inception -> Requirements -> Design -> Architecture -> User Stories/AC -> Development -> Git/PR ->
CI/CD -> Test Automation -> Execution -> Zephyr -> AI Analysis -> Defect/Enhancement -> Feedback.
